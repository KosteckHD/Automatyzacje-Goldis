## Wyniki uruchomione po zmianach

- `npm run build` — wszystkie workspace’y (`core`, `api`, `worker`, `web`) zbudowane poprawnie.
- Ukierunkowane testy API: 19/19 zaliczone, obejmują parser, edycję/anulowanie słownika, moduł, zgodność UUID i politykę grantów.
- Testy Python commission-engine: 23/23 zaliczone w środowisku z `requirements.lock`.
- `scripts/Test-GoldisDatabase.ps1 -Module commission` — zaliczony na jednorazowych PostgreSQL i Redis; potwierdził `auditRollback=atomic`, `revisionRace=exclusive`, `editPublish=serialized`, `concurrentClaims=exclusive`, `recovery=fenced`, `publication=atomic`, `cancel=atomic`, `replay=blocked`, `bullRedelivery=exclusive`; migracje `001–067` zastosowane i powtórzone stabilnie, baza tymczasowa usunięta.
- Pełny `npm run test:unit -w @goldis/api` nie zakończył się czystym wynikiem i został przerwany z powodu zawieszenia. Testy GUS/MF używają lokalnych serwerów-fixture `127.0.0.1`: w sandboxie ich żądania kończyły się `UNAVAILABLE`, natomiast te same dwa pliki uruchomione poza sandboxem przeszły 20/20. Te lokalne błędy transportu nie wskazują na regresję adapterów; pełnego zestawu API nadal nie oznaczam jako PASS.

## Kroki przed wydaniem

1. W środowisku wdrożeniowym uruchomić audytowany dry-run skryptu grantów auditorów. Przejrzeć każdy rekord; użyć `--apply` dopiero w zatwierdzonym oknie i zachować wyjście jako ślad zmian.
2. Zastosować migrację 067, zatrzymać i opróżnić poprzednie workery, po czym wdrożyć API, silnik i worker jako zgodny zestaw. Nie mieszać konsumentów używających starego i nowego protokołu przejęcia.
3. Zbudować i przeskanować dokładny obraz Linux przeznaczony do wydania, łącznie z pakietami systemowymi. Potwierdzić limity kontenera i testy parsera w tym obrazie.
4. Dokończyć pełny przebieg regresji API, a następnie bramki operacyjne audytu: Redis/DB ACL, rzeczywiste HTTPS i zaufana konfiguracja proxy, izolacja procesów oraz cold restore wraz z dziennikiem kasowań.

Do czasu wykonania tych kroków status jest `INTEGRATION_VERIFIED` dla CYB-002/003/005/006 na izolowanych usługach, częściowo zweryfikowany dla pozostałych punktów i **nie jest** statusem `RELEASE_VERIFIED`.
