## Wspólna instrukcja

Use case ui-mockup. Create one ultra high resolution landscape 3840x2400 conceptual contact sheet with exactly FOUR COMPLETE desktop app mockups in a precise 2x2 grid. Each screenshot must have enough resolution for readable Polish UI labels, a consistent 1440x900 desktop viewport proportion, and no clipped content. Narrow neutral black gutters only, clear small numbered Polish screen title above each viewport, no prose elsewhere. Reference image 1 is the approved Goldis dashboard visual language: closely match its flat charcoal matte surfaces, warm gold restrained accents, crisp warm white sans serif labels, fine hairline borders, modest corners, purposeful density, expanded left sidebar with logo at top and profile at bottom. Reference image 2 is the official logo: preserve existing gold umbrella AC Goldis UBEZPIECZENIA identity and crop excess empty margins. Every app screenshot uses the same shell except login: sidebar links Dashboard / Narzędzia / Wyniki / Historia operacji, contextual secondary links Korekty, Audyt if relevant, Administracja only when authorized; quiet bottom Ustawienia and profile. Main header breadcrumb and search. Set matching layout positions and styling across all four screenshots. Show only synthetic demonstration data, not real secrets or customer information. Footer each screen 'Mockup · Dane przykładowe'. Automation results tied to both automation name and operation ID. Avoid fake new tools, gradients, perspective, device frames, glow, giant ornamental cards, placeholder skeletons unless specified. Show distinct full compositions for each requested screen, not four variants of same dashboard. Polish accents and button text must be sharp and readable. Compact gold buttons for primary actions, neutral secondary buttons, muted green success, amber intervention, red errors with text labels. Main UI targets daily use by a small team.
