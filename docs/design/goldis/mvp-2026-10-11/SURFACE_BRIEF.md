# Goldis MVP mockups

Operate surface. Extend the user-approved charcoal/gold visual world using the newly confirmed workflow. No new identity workshop and no questions: the user explicitly requested execution.

## Direction contract
THESIS: shared automation output becomes a working lead pool and a personal queue; the focal moment is assigning an amount of leads and changing a contact outcome in-place.
OWN-WORLD: matte near-black, layered charcoal, warm champagne gold, quiet hairlines and local Hanken Grotesk. Dense but readable rows. Original logo and actual supplied Sidebar component.
STORY: upload and inspect → optionally enrich REGON → mandatory deduplication → confirm start → receive a personal notification → inspect shared pool → manager assigns quantity → employee handles only their assigned leads.
FIRST VIEWPORT: expanded sidebar 300px with profile anchored below; restrained location bar; main results heading and tabs; filter toolbar; dominant lead table; manager allocation panel to its right. The employee's corresponding viewport features status dropdowns and phone/email rather than allocation controls.
FORM: brief-pinned operational table composition, extending the previously approved dashboard. New-world seed is inapplicable: the user preserved the visual world and supplied the interaction component. Code-first mockups, because actual component behavior and exact Polish labels are the deliverable; not a stored global workflow preference.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Scope
Standalone React prototype and rendered PNG mockups; no production frontend or backend edits. Role selector and synthetic examples for review. Screens cover login, dashboard, tools, upload, file inspection/enrichment/deduplication, start summary, task list/detail, automation results index, shared lead pool/assignment, My Results dropdowns, lead detail, launcher-only notifications, manager employee/access control and reports, administrator access/settings/monitoring/audit, and personal account. Include desktop and mobile examples.
