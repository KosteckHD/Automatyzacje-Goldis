# Zrzuty ekranów zaimplementowanej aplikacji Goldis

Zrzuty wykonano z lokalnego builda produkcyjnego aplikacji przez Playwright. Interfejs jest rzeczywisty; odpowiedzi API zastąpiono syntetycznymi fixture’ami, żeby pokazać reprezentatywne stany bez danych klientów.

- Rozdzielczość przeglądarki: 1440 × 1040 px.
- Liczba plików PNG: 35.
- Zawartość: główne trasy, warianty ról, detale leadu i importu, zakładki weryfikacji oraz kadry sekcji panelu administratora.
- [Zbiorczy podgląd](contact-sheet.png) · [klikalna galeria](index.html) · [metadane i ścieżki](screenshots.json)
